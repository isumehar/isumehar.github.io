ISHU MEHAR WEBSITE — QUICK SETUP

1) Extract this ZIP.
2) Create/sign in to a GitHub account.
3) Create a NEW public repository named exactly:
   yourusername.github.io
   (replace yourusername with your GitHub username)
4) Upload index.html and profile.jpg to the repository's main branch.
5) In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
6) After publishing, your site address will be:
   https://yourusername.github.io/

GOOGLE SEARCH:
- Open Google Search Console and add your website as a URL-prefix property.
- Complete ownership verification using the method Google gives you.
- Use URL Inspection -> enter your homepage URL -> Request indexing.
- Google decides when/where the page appears. There is no guarantee it will be the first result, and indexing can take time.

PRIVACY:
Do not publish Aadhaar number, full date of birth, phone number, or full home address.
